# EdgeShield GitHub-maintained rules / 边缘盾规则目录

Scheduled GitHub Actions is ON by default, every six hours on main. Edits to the maintained inputs also trigger the same workflow. No Cloudflare Worker Cron or scheduled() handler is needed.

- sources.yaml: explicit allowlist, approved license, service scope and autoApply controls. Local curated.json is the **safe starter**, not a general upstream security feed.
- curated.json: harmless regression-only marker; replace/extend with operator-reviewed detection rules.
- baseline.json and regression.json: required baseline and independent attack/legitimate samples.
- active.json: generated by the Action ONLY if all source and full merged regressions pass; changes stay in GitHub.
- inventory.json: add exact installed origin software versions; empty by default because a Worker cannot know private origin versions.
- cve-candidates.json: OSV advisories for EdgeShield's actual installed npm dependencies and operator-supplied origin inventory.
- emergency-paths.json: optional preapproved full-feature isolation paths. Default empty; no CVE-driven blocking occurs automatically.

External upstream rule feeds: configure a vetted HTTPS location in sources.yaml, an accurate allowed license, and regression fixtures that independently cover every rule. SecLang/CRS and ambiguous conversions cannot be silently installed. A failing source/test/CVE request leaves committed files unchanged.

Security: The Action only commits active.json and cve-candidates.json under rules/. It never edits Cloudflare POLICY, routes, origin, Keyless SSL or DNS. Deploy new policies through a separate operator-approved process. OSV risk reports are candidates, not proof of exploitation or a vendor fix. Temporary isolation requires fresh evidence, bounded TTL, approval and rollback.

中文：默认每 6 小时自动更新 GitHub 仓库 /rules 下的已验证生成文件。仅允许事先批准的规则源与测试；云端 Worker 不参与定时同步，不自动发布线上规则。请根据真实上游来源配置 sources.yaml，初始探针不能代替真实防御规则。
